# Random User Generator

A simple Random User Generator built using HTML, CSS and JavaScript.

This was my first project using the Fetch API, where I learned how to fetch data from an external API and dynamically display it on a webpage.

## Features

- Generate a random user
- Display profile picture
- Display full name
- Display age
- Display gender
- Display email
- Display phone number
- Display country
- Handle API requests using Fetch API
- Dynamically update the DOM

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Random User API

## What I Learned

- Making API requests using `fetch()`
- Working with asynchronous JavaScript
- Using `async/await`
- Converting API responses using `.json()`
- Accessing nested objects from API responses
- Updating HTML elements using the DOM
- Handling API errors
